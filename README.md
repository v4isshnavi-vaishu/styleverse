# 👗 Style Studio – Fashion Store Website

## 📌 Project Description

Style Studio is a modern, attractive, and responsive Fashion Store Website developed using **HTML5 and CSS3**. The website is designed to showcase the latest fashion trends, clothing categories, products, special offers, and featured collections.

It provides users with a simple and user-friendly shopping experience where they can explore different fashion styles and discover trending products.

## ✨ Features

- **Home Section:** Attractive hero section with a fashion background image and shopping button.
- **Categories Section:** Displays different clothing categories such as Women's Wear, Men's Wear, Kids Wear, and Accessories.
- **Products Section:** Showcases trending fashion products with images, descriptions, and prices.
- **Special Offers:** Highlights exciting discounts and seasonal sales.
- **Featured Collections:** Displays exclusive summer and classic fashion collections.
- **Shopping Section:** Encourages visitors to explore and shop for the latest styles.
- **Contact Section:** Provides store location, phone number, email, and working hours.
- **Navigation Bar:** Easy navigation between different website sections.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the webpage.
- **CSS3** – Used for styling, layouts, colors, animations, and responsive design.
- **Unsplash** – Used for fashion and clothing images.
